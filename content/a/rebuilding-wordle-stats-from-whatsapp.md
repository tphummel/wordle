Found a great post: [Rebuilding Wordle stats from WhatsApp][0] by [omgmog][1]. Most Wordle groups I'm in share their daily emoji grid in a group chat rather than anywhere structured, so reconstructing real stats means mining that chat history instead of an API or local storage dump. It's a fun variation on the same problem this site was built to solve - getting decent Wordle analytics out of a format that was never meant to be analyzed.

Worth a read if you're into digging usable data out of places it wasn't meant to live.
